مُقتدِر — حزمة نشر جاهزة (Static Web App)
==========================================
هذا المجلد يحتوي على كل ما يحتاجه الموقع: ملف واحد اسمه index.html.
لا توجد ملفات CSS/JS منفصلة ولا صور خارجية — كل شيء (التصميم، الأكواد، الشعار) مدمج داخل هذا الملف الواحد.
لا يعتمد على أي رابط محلي (file://, C:\, /Users/, إلخ) ولا على أي شيء خاص ببيئة تطوير معينة.

الرفع (اختر واحدة، كلها تعطيك رابط HTTPS خلال دقائق):
1) Cloudflare Pages: dash.cloudflare.com → Workers & Pages → Create → Pages → Upload assets → اسحب هذا المجلد.
2) Netlify Drop: app.netlify.com/drop → اسحب هذا المجلد → رابط فوري.
3) GitHub Pages: أنشئ مستودعًا → ارفع index.html → Settings → Pages → فعّل من الفرع الرئيسي.

بعد الرفع، افتح الرابط من Safari على آيباد أو آيفون — هذا هو المسار المضمون والمختبر.
